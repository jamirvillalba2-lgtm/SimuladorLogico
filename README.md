## Simulador de compuertas logicas

Aplicacion grafica en Tkinter para simular compuertas utilizadas en diseño de circuitos digitales:
AND, OR, NOT, NAND, NOR, XOR, XNOR y BUFFER.
Cada vista permite cambiar sus entradas, consultar la salida mediante un LED virtual y revisar la tabla de verdad.
El panel de fundamento teorico muestra la formula booleana, la regla de funcionamiento y el razonamiento de la salida actual.

### Ejecucion

Desde la carpeta del proyecto:

```bash
python main.py
```

La navegacion lateral permite cambiar entre todas las compuertas.
